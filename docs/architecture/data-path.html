Trace vocabulary

  
With ScanConfig::trace set, every candidate emits a StageEvent at each
    decision. This is the complete set the scanner can produce — three phases, because runtime and alternate patterns
    take shorter paths than the primary loop. It is what /v1/scan/explain returns.
