# Bill of materials

Generated by `scripts/generate-sbom.sh`. CycloneDX 1.6 documents sit
beside this file, one per shipped artifact.

**There is no single BOM for this repository.** Each artifact links a
different closure, and the differences matter: `siphon-api` links none of
rusqlite, unrar, rxing or the image codecs, while `siphon-fs` and
`siphon-smtp` link all of them. A workspace-wide document would claim
siphon-api ships a bundled SQLite and a C RAR decoder it has never
contained.

Resolved per package for `x86_64-unknown-linux-gnu`, normal edges only — dev- and
build-dependencies are not components of a shipped binary. Note that
`cargo metadata` and `cargo tree --workspace` unify features across
members and report that false picture; `cargo tree -p` does not.
